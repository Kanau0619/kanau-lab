# AI Character Portfolio 图片上传说明

网站已经为四个项目分别保留图片目录：

```text
public/images/
├── zhan-chenyi/
├── yu-zhi/
├── huo-bingchu/
└── yin-zhaoye/
```

## 每个项目默认支持

1. `hero.webp`：Hero 主视觉一张。
2. `result-01.webp`：真实项目截图一张。
3. `result-02.webp`：第二张真实项目截图，可选。
4. `result-03.webp`：第三张真实项目截图，可选。

推荐使用 WebP，Hero 图片至少 1600px 宽，项目截图保持原始 PC 或手机比例，
不要强行拉伸。

## 添加 Hero 图片

以虞执为例，将图片放到：

```text
public/images/yu-zhi/hero.webp
```

然后在 `src/data/projects.js` 的虞执项目中填写：

```js
heroImage: "/images/yu-zhi/hero.webp",
```

## 添加 Result 截图

将图片放到：

```text
public/images/yu-zhi/result-01.webp
public/images/yu-zhi/result-02.webp
```

然后填写：

```js
gallery: [
  {
    src: "/images/yu-zhi/result-01.webp",
    alt: "虞执项目 PC 端实际界面",
    caption: "PC 端 Interactive Status UI",
  },
  {
    src: "/images/yu-zhi/result-02.webp",
    alt: "虞执项目移动端实际界面",
    caption: "移动端响应式效果",
  },
],
```

`gallery` 保持空数组时，网站不会显示灰色图片占位或多余空白。

## 关于在线上传后台

当前采用代码与目录管理图片，不在公开作品集上显示上传控件。这样可以避免匿名访客
上传或覆盖你的作品素材。

如果后续需要“登录后在线上传图片”，应另外配置：

- 管理员身份验证
- 私有上传页面
- 对象存储
- 文件类型与大小限制
- 图片删除和替换权限

这些功能不应直接暴露在公开求职作品集页面中。
