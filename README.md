## About

Kanau Lab 是一个面向 **AI 角色内容策划、AI 陪伴产品、Conversation Design 与 AI 内容 / 产品运营** 岗位整理的个人作品集。

这里不以“角色设定展示”为终点，而是记录角色从概念到可运行交互的设计过程：如何定义 Persona、控制主动性、关系节奏与信息边界，如何组织 Prompt / World Info / 状态变量，以及如何通过多模型测试、Bad Case 分析与迭代改善角色一致性和交互体验。

## What I Did

- AI Character / Persona 设计与行为约束
- 多场景 Conversation Entry、Timeline Context 与关系边界设计
- Prompt 结构、World Info / Knowledge Context 与信息边界设计
- 状态变量、结构化输出、Regex 解析与交互信息展示
- ChatGPT / Gemini 等模型的实际交互测试与 Bad Case 复测
- 需求拆解、问题复现、跨端验证与迭代

> 代码实现由 Codex 辅助完成；角色设计、交互逻辑、Prompt 结构、测试标准与最终效果验证由本人完成。
